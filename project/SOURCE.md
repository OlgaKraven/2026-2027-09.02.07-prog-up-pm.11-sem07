# Происхождение материалов

Основа задания: КИМ 09.02.07-2-2027, том 1, задание 1 «Разработка базы данных средствами СУБД», страницы 35–36. Описание области: приложение 1, раздел БУ. Импортные таблицы и изображения: приложение 2, раздел БУ. Материалы ДЭ предоставлены преподавателем. Excel преобразован в CSV UTF-8 с английскими заголовками, датами YYYY-MM-DD HH:MM:SS и десятичной точкой; содержательные данные сохранены. Исправление двух обнаруженных расхождений названий показано отдельно в SQL и методичке.

Демонстрационная схема, SQL и индивидуальные дополнительные задания разработаны для этого комплекта. Роли СУБД, транзакции, индексы и резервное копирование расширяют основу ДЭ для целей ПМ.11. Индивидуальные CSV являются учебными синтетическими данными.
