# Демонстрационная БД «Пара»: MySQL в XAMPP

Проверенная среда: MariaDB 10.4.32 и phpMyAdmin 5.2.1. Следуйте полной методичке: создайте pm11_demo с utf8mb4_bin; выполните 01_schema.sql и 02_staging.sql. Импортируйте пять CSV data/demo в соответствующие stg_таблицы, разделитель запятая, кавычка двойная, первая строка пропущена. Проверьте несогласованности и выполните исправления из 03_import.sql. Диагностические SELECT должны вернуть пустые результаты. Затем выполните импорт от START TRANSACTION до COMMIT одним запросом. До собственного оформления ожидаются 31 товар, 35 размеров, 92 позиции, 20 пользователей, 10 заказов и 30 строк; сумма исторических заказов 341770.00, сумма доступного количества 1274.

Выполните 04_queries.sql и создайте 05_order.sql целиком. Один CALL place_order управляет всей транзакцией и возвращает номер заказа. Не оборачивайте CALL во внешнюю транзакцию: START TRANSACTION внутри процедуры завершает ранее открытую. Ошибка вызывает ROLLBACK и RESIGNAL. 06_checks.sql содержит и успешные, и намеренно ошибочные проверки; выполняйте их отдельными логическими блоками, фиксируя состояние до и после. DDL в MySQL не откатывается обычным ROLLBACK.

07_roles.sql выполняется администратором после создания процедуры. Для своей БД измените её имя в GRANT. Роли существуют на уровне сервера, повторно их не создавайте. Личные пароли задавайте локально в phpMyAdmin и не сохраняйте в репозитории. Используйте ограниченные учётные записи для проверки реальных запретов; SET ROLE в сеансе root не является такой проверкой. Операционная роль имеет только SELECT и необходимые права для копирования, а также UPDATE отдельных колонок. Она не получает DROP или полномочия на другие БД. DEFINER процедур/представлений должен существовать при восстановлении; восстановление на том же учебном сервере выполняется администратором.

Данные демонстрации получены из приложения 2 КИМ 09.02.07-2-2027, БУ, с преобразованием Excel в CSV. Исходные несогласованности названий сохранены для разбора в методичке. Файлы Images приложены для проверки поля image_path. Все индивидуальные наборы созданы для учебного комплекта; демонстрационное решение используется для сверки после самостоятельной работы.
