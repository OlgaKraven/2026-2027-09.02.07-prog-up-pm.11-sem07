# Демонстрационная база данных «Пара»

Модель, исходные данные и объяснения показывают способ проектирования и импорта. Обязательная работа выполняется один раз на собственной предметной области; повторное создание демонстрационной БД не требуется.

Прочитать полное задание и методические рекомендации. Создать собственную БД utf8mb4_bin; сохранить схему и ER; выполнить 01_schema.sql и 02_staging.sql. Загрузить пять CSV своего варианта с явным списком столбцов без source_file и source_row. Выполнить 03_import.sql целиком. Помощник import_checked сначала записывает причины отклонений и останавливается до переноса при ошибках. После решения причин повторить CALL import_checked();. При успешном переносе выполнить 04_queries.sql и сверить числа, связи и историческую сумму.

INPUT_MAPPING.md связывает оригинальные XLSX и CSV. DATA_DICTIONARY.md объясняет поля. HANDOFF.md задаёт состав и проверку передаваемого пакета. Исходные CSV не изменяются; исправления промежуточного слоя сохраняются в import_issue.

Для демонстрации ожидаются 31 модель, 35 маркировок, 92 позиции, 20 клиентов, 10 заказов и 30 строк. Историческая сумма 341770.00, доступное количество 1274. Для своего варианта использовать context.json.

Файлы 05_order.sql, 06_checks.sql, 07_roles.sql, 08_adaptation.sql и 04_queries_with_index.sql относятся к разделу для углубления и не входят в приёмку основного результата. Их подробные объяснения сохранены отдельно. SQL ролей выполняется только администратором; личные пароли не сохраняются в проекте.
