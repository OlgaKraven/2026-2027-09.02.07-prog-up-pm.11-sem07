# Проект базы данных собственной области

Скачать один назначенный variant-NN.zip и распаковать его. Проверить папки sql, data, er, docs и checks; недостающие создать. В data/variant-NN оставить без изменений пять CSV и context.json своего варианта. Прочитать задание и методику. На каждом этапе применить разобранный приём сразу к собственной БД pm11_vNN; отдельное воспроизведение «Пары» не требуется.

Сохранить SQL схемы, промежуточного слоя, проверки, импорта и контроля. В er поместить ER.pdf; в docs — словарь полей и карту источников; в checks — журнал и контрольные значения. Следовать docs/HANDOFF.md в распакованном комплекте своего варианта. В заполненном «Отчет о выполнении.docx» обязательно указать ссылку на репозиторий.
