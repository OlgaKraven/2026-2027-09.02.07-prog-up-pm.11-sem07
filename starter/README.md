# Проект базы данных собственной области

Создать папки sql, data, er, docs и checks. В data сохранить без изменений пять CSV и context.json из data/variant-NN общего архива исходных материалов. Прочитать задание и методику. На каждом этапе применить разобранный приём сразу к собственной БД pm11_vNN; отдельное воспроизведение «Пары» не требуется.

Сохранить SQL схемы, промежуточного слоя, проверки, импорта и контроля. В er поместить ER.pdf; в docs — словарь полей и карту источников; в checks — журнал и контрольные значения. Следовать HANDOFF.md. В заполненном отчёте обязательно указать ссылку на репозиторий.
