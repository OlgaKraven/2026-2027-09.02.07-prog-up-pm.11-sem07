# Проект базы данных торговой организации

Начните с методички и описания своего варианта. Создайте отдельную БД utf8mb4_bin в phpMyAdmin. В рабочей папке создавайте SQL-файлы по порядку построения решения: схема, промежуточные таблицы, импорт, запросы, процедура, проверки и права. Данные находятся в отдельном архиве вашей области. Эта заготовка не содержит готового решения.

Товары имеют размерные позиции. Остаток относится к конкретной позиции, цена — к модели; строка заказа сохраняет цену покупки. Клиенты предметной области и учётные записи СУБД имеют разные назначения.

При сдаче проекта приложите ссылку на его репозиторий.
