# Сборка материалов УП ПМ.11

Порядок: `prepare_course.py`, `prepare_documents.py`, `build_report.py`, обновление полей DOCX через Word (`render_word.ps1`), `build.py`, `export_pdf.cjs`, снова `build.py` для итоговых контрольных сумм, затем `check_package.py`.

`build_report.py` адаптирует копию общего мастера из `forms/template/`. Итог — `forms/Отчет о выполнении.docx`. Общий мастер не изменяется. Старые формы сохранены в `forms/archive/`; прежний `export_report.py` относится к архивному Markdown и в текущую сборку не входит.

Исходные снимки реальных окон хранятся в `evidence/walkthrough/`. Координаты читаемых фрагментов и пояснения задаются в `illustrate_course.py` и `focus.json`. HTML сохраняет полный оригинал и показывает нужный фрагмент непосредственно после действия. PDF встраивает эти изображения внутрь разделов.

Первоначальные расширения остаются в `content/extensions.json` и `project/reference/`. Проверки SQL запускаются на отдельном учебном экземпляре MariaDB. `09_checks_walkthrough.sql` содержит независимые опыты с ожидаемыми ошибками; запускать весь файл одним пакетом нельзя.
